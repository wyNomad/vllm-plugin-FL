## 假设与改动

- MiniCPM5-2B 的头数为 Q=16、KV=2，GQA=8；本镜像 vLLM 0.24 在 2 KV 头时将 2D/3D 解码切换阈值设为 64 条序列，而正式基准并发上限也是 64。值得检查高并发纯解码是否长期留在 3D 路径。
- 容器镜像源码的 BF16/auto 非量化 KV 分支仍传入 `k_descale`、`v_descale`。候选在 `KVQuantMode.NONE` 时改为 `None`，保留量化 KV 路径。
- 环境开关 `VLLM_FL_NATIVE2D_PROBE=1`、KV 非量化、head size=128、GQA=8 且批次含预填充或至少 16 条解码序列时，让现有 Triton unified attention 用 2D kernel，并尝试 `BLOCK_M=128`、KV tile=16、`num_warps=8`、`num_stages=2`。小批纯解码仍走原选择。现有内核没有原报告所说的独立 `pipeline_stages` 参数，因此未臆造该设置。
- 这是对个人 **`--rm` 一次性容器内已安装 vLLM** 的补丁；服务器和本地个人插件仓库保持原样。`patch_vllm.py` 验证两个原文件的 SHA-256，保存原件、diff 和补丁后 SHA；容器删除即回退。
