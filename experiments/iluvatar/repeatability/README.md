# Native 2D 重复性实验

复测已经通过精度门槛的第一版 Native 2D，不修改内核或路由。上一轮是候选→基线；本轮用同一张 GPU 1，按基线→候选顺序串行执行，两组分别创建一次性个人容器。

- 固定原镜像摘要、服务参数、补丁脚本及补丁后的两个源码哈希。
- 使用原版 `benchmark_throughput_serve.py`，4k 为 `[4096,1024,64,256]`，16k 为 `[16384,1024,64,128]`；各四轮，舍弃首轮。
- 完整性要求：每组八轮，1536/1536 请求成功，输入/输出 token 总数与配置相符，CSV 汇总与后三轮复算一致。
- 保存插件/FlagGems 提交、镜像摘要、命令、源码证据、GPU 状态、原始 CSV、组内 CV 与两轮均值变化。
- 分别报告 4k 回退和 16k 提升。两次独立运行不能直接给出跨次置信区间；本轮用于确认提升是否复现，不预设提升百分比。

服务器以后台进程运行：

```bash
python3 /workspace/wyNomad/vllm-plugin-FL/experiments/iluvatar/repeatability/run_repeat.py \
  --run-id native2d_repeat_20261011
```

必须通过脱离 SSH 的后台启动器运行以上命令。脚本拒绝复用已有结果目录、占用超过空闲阈值的 GPU 或已有个人容器；不操作他人容器。个人 GPU 文件锁防止该脚本重复启动。每阶段自动清理容器，失败停止后续阶段并保留日志。

结果写到 `/workspace/wyNomad/results/native2d_repeat_20261011/`，`run.exit` 为整体退出码，`current_stage.txt` 为状态；成功后生成 `REPORT.md`、`comparison.json` 和结果校验清单。上一轮资料保持原样。预计总时长约 7–9 小时，实际完成时间以日志为准。

本轮不重跑 Math500：补丁及生效源码必须与上一轮精度 0.981 的候选精确一致。下一版长上下文路由仍未启用。完成后把 CSV 和报告同步到本地，再归档提交；完整日志保留宿主机个人目录。
